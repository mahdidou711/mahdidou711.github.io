# Portfolio V2 — Bouama Mehdi

Version historique du portfolio React/TanStack Start de Bouama Mehdi, orienté électronique, FPGA et logiciel embarqué.

Le site de production associé à <https://mehdibouama.me/> est maintenu dans un projet distinct et déployé via Cloudflare Workers Static Assets. Ce dépôt n'est pas sa source de production.

## Développement local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Preview locale

```bash
npm run preview
```

## Déploiement (historique)

Les paramètres Vercel ci-dessous concernent cette ancienne version V2. Ils ne décrivent pas le déploiement actuel sur Cloudflare Workers. Le fichier `CNAME` est conservé ; sa présence ne prouve pas que GitHub Pages sert le site principal.

- Build command: `npm run build`
- Install command: `npm install`
- Root directory: racine du repository

L’ancien portfolio HTML/CSS est conservé dans `legacy-v1/`.
